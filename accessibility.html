Accessibility

Accessibility statement

Dark Star Literary Agency is working to make its public website and future digital materials easier to use across devices, input methods, and assistive technologies.

This statement describes the current implementation and known limitations. It is not a claim that every page or source file has completed formal conformance testing.

Current website features

Accessibility built into the public site

Keyboard access

Pages include a skip link, visible keyboard focus treatment, semantic headings, descriptive links, and standard controls that do not require a mouse.

Reduced motion

Media-rich pages respect reduced-motion preferences. Automatic previews pause when reduced motion is requested or when the page is not visible.

Controlled media

Archive motion previews load only after selection, use visible controls, remain muted, and include poster images and fallback text.

Structured content

Public pages use headings, lists, text alternatives for images, page titles, descriptions, and a consistent navigation structure.

Known limitations

Work that is still in progress

Known limitations are recorded directly rather than being presented as completed accessibility work.

Companion source PDFs

The 44 supplied companion interiors are image-based production sources. The July 11, 2026 baseline review found no usable extractable text in those source files.

They are not currently offered on this website as accessible digital editions. A source PDF will not be labeled screen-reader ready or linked as an accessible download until text, semantic tags, reading order, language metadata, meaningful alternatives, and manual assistive-technology review are verified.

Visual activities

Search-and-find pages, mazes, tracing exercises, coloring pages, and visual puzzles may require a structured HTML, tagged document, descriptive text, or another alternative format to provide meaningful nonvisual access.

Third-party services

Links may lead to third-party services such as Amazon. Dark Star Literary Agency does not control the accessibility or current behavior of those external sites.

Ongoing testing

Automated repository checks cover page structure, image alternatives, unsafe media behavior, source traceability, and release claims. Manual keyboard and assistive-technology testing remains an ongoing process.
